# ISLAND

一个用 Three.js 构建的交互式 3D 海岛，可以环顾、缩放、切换昼夜与天气，也可以点亮蜡烛、许愿和看烟花。

[进入海岛](https://lamees-g.github.io/island-3d/)

- 当前在线版：`docs/index.html`。
- 离线体验：下载并解压仓库 ZIP，用支持 WebGL 2 的浏览器打开 `docs/index.html`。
- 更新网页：将最新打包的 `index.html` 更新到 `main` 分支的 `docs/` 目录，GitHub Pages 会自动发布。
