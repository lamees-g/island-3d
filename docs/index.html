自由参观　拖动旋转，滚轮缩放，右键拖动平移；触屏单指旋转、双指缩放和平移。
岛上小事　点躺椅或栈桥，坐下看海，再点画面返回；点亭檐风铃，让风替你奏一小段；夜里点门廊灯笼可调亮、调暗，点近岸海水泛起一圈涟漪。风铃声跟随右上角环境音开关。
天气故事　小雨时在栈桥看海，中雨时到凉亭听雨，暴雨时望向灯塔；白天雨停后去海上看一段彩虹。转场时设置会自动收起，到位后展开；点“海岛设置”也可手动收放。转场中拖动画面，就能接管镜头。
为今天庆祝　点亮蜡烛，许一个愿，再轻轻吹灭；也可直接点击蛋糕。随时点右上角关闭，回到之前的海岛时光。
快捷键　N 昼夜，F 天气，H 纯净画面，R 回到海湾，Esc 关闭卡片。
